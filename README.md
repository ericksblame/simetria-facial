# Simetría facial

App web que usa la cámara para medir la simetría del rostro (ojos, cejas, comisuras, mandíbula y mentón, nariz e inclinación de la cabeza), muestra los puntos de referencia en vivo y da recomendaciones de hábitos y ejercicios en español.

- Todo se procesa en el navegador con MediaPipe Face Landmarker; ninguna imagen sale del dispositivo.
- El historial guarda solo números, en el navegador de cada dispositivo.
- No es un diagnóstico médico. Los ejercicios y hábitos tienen efectos limitados y no cambian la estructura ósea. Ante una asimetría repentina, acude a urgencias.

**En el Mac:** doble clic en `Abrir Simetria.command` (o `python3 server.py`).
**En el iPhone:** abre la página publicada en GitHub Pages con Safari y añádela a la pantalla de inicio.
